# Implementation plan – ReflexEnglish guest-first web app (lean: 8 slices, 4 waves, ~90 core tests)

Binding inputs: `.claude/CLAUDE.md`, `docs/PRD.md` §1, `docs/use-cases/guest_first_web_app_use_cases.md`, `docs/architecture/guest_first_web_app_review.md` (+ Addenda 1–3), `docs/qa/guest_first_web_app_test_cases.md` (reference catalogue; implement ONLY the TC ids listed per slice). All paths relative to repo root. TDD: write the listed tests first, see them fail, implement, see them pass, commit (1 slice = 1 commit, no push, no AI attribution lines).

Cross-wave conventions:
- Slice 1 creates every router module as a stub (`router = APIRouter()`) and wires it in `main.py`; later slices only edit their own router file.
- Slice 5 creates stub frontend screens for practice/reflex/addphoto/review; slice 8 fills them.
- `backend/tests/api/test_gate.py` (TC-4.3) walks `app.routes` against an exempt-list constant so later routes are covered without editing it.
- Tests use `create_app(settings, clock=FakeClock, provider=MockProvider)`; no real network, no real Gemini.

### Slice 2 – Pure rule engines [ARCH-REVIEW]
Files (new): `backend/app/services/scoring.py`, `srs.py`, `stats.py`, `validators.py`, `policy.py`; unit tests `backend/tests/unit/test_scoring.py`, `test_srs.py`, `test_stats.py`, `test_unlock_rules.py`, `test_nickname_validation.py`, `test_age_rules.py`, `test_usage_gate_logic.py`, `test_ratelimit_window.py`, `test_card_visibility_policy.py`.
Tests first (22): TC-28.2, 28.3, 29.2, 29.18 (scoring); 28.4, 28.5, 28.21 (SM-2); 16.14, 32.10 (streak/XP/mastery); 27.3, 29.19, 47.6 (unlock); 8.1, 8.2 (nickname/password); 8.3, 8.4 (age/guardian); 3.9, 3.19, 4.19 (idle/gate arithmetic); 13.17 (sliding window); 25.13, 25.19 (visibility, share decision).
Changes: pure functions, no app/sqlite/fastapi imports. Accuracy: NFKC-lowercase, whole-word match = 100, else fuzzy capped at 60; sentences = word recall. Score `0.6·acc + 0.4·speed·[acc≥70]`; timeout only when `ms > limit`; round half up. SM-2 (Addendum 2 #1): q map ≥90→5, ≥80→4, ≥70→3, ≥50→2, ≥20→1 else 0; q<3 → reps=0, interval=1, lapses+1; else intervals 1, 6, then `round(prev × ease_after_update)`; ease floor 1.3. XP 10 if score ≥70 else 2; streak = consecutive `Asia/Ho_Chi_Minh` days with an attempt ending today/yesterday; level = floor(XP/500)+1; mastery = mean of last ≤5 attempts. Practice level unlock: mean of latest per-item scores ≥70 (unattempted = 0). Reflex unlock (simplified): after a session with ≥5 answered rounds and mean ≥80 the next level unlocks. Nickname: NFKC then ASCII `[A-Za-z0-9_.-]` 3–20; password ≥8; age by ICT year, min 10, guardian email+consent required under 16. Overrides: 1–8 labels, word 1–40, title ≤60, no new labels. Gate: `is_new_session` strictly greater than idle; `gate_required(prior_write_sessions, free_sessions)`. `window_exceeded` (boundary: events with age ≥ window are outside). Policy: `can_view`, `share_decision` priority faces → personal info → unsuitable.
Verify: `python -m pytest backend/tests/unit -q -k "scoring or srs or stats or unlock or nickname or age or usage_gate or ratelimit or visibility"`

## Deferred / deviations from the architecture review (recorded)
Maintenance loop → once at startup + CLI; no gate grace window; `reflex_progress`/`user_settings`/`audio_assets` tables dropped (columns on users/labels instead); Reflex unlock simplified; no lease/lazy-sweep (stale-on-read) and no `manual_retries` (hard cap 6 only); offset/limit pagination instead of keyset cursors; no `TRUSTED_PROXY_HOPS`; no `/__test__/clock` (e2e uses `SESSION_IDLE_SECONDS=3`); no session rotate-on-use (sliding idle expiry); ~600 remaining QA cases (P1/P2, perf, a11y, offline) not implemented.

## Commands
Setup: `python -m pip install -r requirements.txt; python -m playwright install chromium; python tools/sync_audio.py`. Run: `python -m uvicorn backend.app.main:app --reload --workers 1`. Tests: `python -m pytest backend/tests -q`, `python -m pytest e2e -q`.
Risks: run with `--workers 1` (per-process AI semaphore/BackgroundTasks); school NAT may still hit the 100 failures/IP limit; fuzzy cap of 60 may block unlocks for accented speech; guardian consent legally unverified (OQ-63); slices 4/5/6/8 exceed ~250 lines (trade-off for ≤8 slices).
