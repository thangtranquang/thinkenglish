Hi everyone, this is my new little project so dont expect much about this!
So basically , me and my mate is creating this website or whatever u called them to practice English for certain people.
Instead of choosing the direct way of doing quiz, practicing grammars like normal English learning apps do like Duolingo, we decided to make this as a daily life things.
To start off, this is heavily supported for mobile, pc/laptop is still useable but its significantly harder.
But overall, we wanted u to take a picture of things in daily life everyday, the website will monitor and see the items of the images and process them, then will give out English words for u to practice.
This is still a demo version, so if u have any feedbacks, questions or suggestions, please tell us.
